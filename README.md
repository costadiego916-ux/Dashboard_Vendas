# Dashboard de Vendas

Dashboard desenvolvido com Excel, Power Query, DAX e Power BI para analisar os principais indicadores de vendas.

![Dashboard de Vendas](dashboard-vendas.png)

## Indicadores

- Quantidade vendida e devolvida
- Faturamento bruto
- Clientes atendidos
- Preço médio
- Produtos vendidos

## Análises

- Faturamento por período e categoria
- Quantidade vendida por produto
- Clientes por gênero e faixa etária

## Ferramentas

Excel | Power Query | DAX | Power BI

## Fonte dos dados

Base disponibilizada para fins educacionais. O arquivo original não está sendo redistribuído.

## Como visualizar

Baixe o arquivo `Dashboard_Vendas.pbix` e abra no Power BI Desktop.
